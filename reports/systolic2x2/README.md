# Recorded SKY130HD run

These files are a copy of one completed `scripts/run_systolic2x2.sh` run.
The live flow still writes under gitignored `work/systolic2x2/`.

Read `summary.md` first. Final layout files are in `results/systolic2x2/`. `6_finish.rpt` is timing, area, and power.
`6_drc_count.rpt` is the KLayout DRC count. `6_lvs.log` is the LVS verdict.
Power is a vectorless estimate. DRC/LVS here is an educational check, not tapeout signoff.
